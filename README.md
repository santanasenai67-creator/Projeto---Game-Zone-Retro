# Projeto---Game-Zone-Retro
Trabalho GameZone Retro
 Sobre o projeto

O Game Zone Retro é uma página web criada em HTML com o objetivo de apresentar uma loja fictícia de jogos clássicos e consoles retrô.

A página apresenta informações sobre os consoles disponíveis, alguns jogos e seus respectivos preços.

 Instagram

 Objetivo

O objetivo do projeto é desenvolver uma página HTML simples para apresentar uma loja de jogos retrô, praticando conceitos básicos de desenvolvimento web, como títulos, parágrafos, listas, links, imagens e tabelas.
