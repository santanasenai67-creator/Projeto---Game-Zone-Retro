 Game Zone Retro
 Sobre o projeto

O Game Zone Retro é um projeto desenvolvido em HTML que representa uma loja de jogos clássicos. A página apresenta alguns consoles retrô, jogos disponíveis e seus respectivos preços.

 Objetivo

O objetivo do projeto é praticar a criação de páginas web utilizando HTML, trabalhando com textos, listas, imagens, links e tabelas.
